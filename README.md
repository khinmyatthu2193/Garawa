# ဂါရဝ --- Garawa 🌸

> **အဝေးကနေလည်း ချစ်ခြင်းနဲ့ ကန်တော့နိုင်တယ်။**\
> *A little offering. A lot of love.*

Garawa is a Myanmar-inspired digital ကန်တော့ experience for Thadingyut and
other moments when people want to express respect, gratitude, and love
to parents, grandparents, teachers, elders, and loved ones from afar.

Create a personalized digital offering, choose thoughtful virtual items,
add heartfelt wishes, and share a private link so the recipient can open
a warm, festive experience of their own. Recipients can read the
message, receive blessings and respond with a thank-you or optional
playful မုန့်ဖိုး gesture.

## 🌼 The Vision

Distance should not stop us from showing respect. Garawa brings a little
of Myanmar's traditional spirit of ဂါရဝ into a delightful digital
experience---warm lanterns, flowers, traditional motifs, a carefully
arranged offering tray, and sincere words from the sender.

Garawa is a symbolic digital experience. Unless a future version
explicitly integrates a supported payment provider, selecting an
offering does **not** purchase or deliver a physical item and the မုန့်ဖိုး
feature does **not** transfer money.

## ✨ Planned Features

### MVP

-   Create an offering for a recipient with the recipient's name and
    sender's name.
-   Select virtual offering items from a curated catalog.
-   Write a personal ကန်တော့ message, wishes, and words of gratitude.
-   Preview the offering before creating it.
-   Generate a unique shareable link.
-   Open a recipient-facing page with a welcoming, step-by-step offering
    reveal.
-   Display selected offerings and the sender's message.
-   Let the recipient send a simple thank-you or blessing response.
-   Responsive, mobile-first interface with Burmese and English-ready
    text.
-   Respectful Myanmar-inspired visual design and accessible motion
    controls.

### Later ideas

-   More themes and seasonal decorations.
-   Optional sound and background music, off by default.
-   A digital မုန့်ဖိုး / gift-back flow, only after the consent, privacy,
    and payment model is defined.
-   Sender dashboard for managing offerings.
-   Link expiry, revocation, or recipient access controls.
-   Additional languages and share-card previews.

## 🎨 Visual Direction

Warm lantern gold, cream, lacquer red, leafy green, lotus flowers,
subtle Myanmar motifs, and friendly illustrations. The experience should
feel festive and culturally grounded without becoming visually crowded
or treating the ceremony as a joke.

Playful မုန့်ဖိုး moments should remain optional and pressure-free. Respect
and gratitude come first.

## 🛠️ Proposed Technology

The implementation stack is not yet final. A practical starting point
could be:

-   **Frontend:** Next.js with React and TypeScript
-   **Styling:** Tailwind CSS
-   **Motion:** Framer Motion or CSS animations
-   **Backend / Database:** Supabase, if persistence is needed for the
    MVP
-   **Deployment:** Vercel

Choose the final stack after the detailed requirements and data model
are agreed.

## 🚀 Getting Started

This repository is currently in the planning stage. Once the application
scaffold is added:

1.  Install the dependencies.
2.  Configure the required environment variables in `.env.local`.
3.  Run the development server using the command documented by the
    chosen framework.
4.  Never commit secrets or service-role keys.

## 🤍 Guiding Principles

-   **Respectful:** honor the meaning of ဂါရဝ and ကန်တော့.
-   **Personal:** every offering carries someone's own words.
-   **Accessible:** simple to use on a phone, even for less technical
    recipients.
-   **Private by design:** share only what is necessary and make link
    behavior clear.
-   **Honest:** clearly distinguish virtual offerings from real-world
    purchases or transfers.
