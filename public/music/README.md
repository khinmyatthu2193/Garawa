# Garawa music library

This folder is reserved for project-owned, public-domain, or properly licensed
audio only. No audio files are included yet, so Garawa shows a friendly empty
library and keeps playback controls disabled.

To add a track:

1. Place the audio file in this folder using a stable, web-safe filename.
2. Add one entry to `lib/music/catalog.ts` with a stable ID, title, artist or
   composer, mood, `/music/<filename>` source, and exact attribution and license
   text. Add artwork and duration only when they are available.
3. Confirm the license permits this use and keep a copy of the license/source
   information with the project records.

Never add a track with invented or missing credits.
